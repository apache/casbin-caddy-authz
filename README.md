# casbin-caddy-authz

> **Deprecated:** this project is no longer maintained. It will not receive any further releases, bug fixes or security fixes, and this repository will be retired. Do not use it in new deployments, and remove it from existing ones.

casbin-caddy-authz was an authorization middleware for [Caddy](https://github.com/caddyserver/caddy), based on [Apache Casbin](https://github.com/apache/casbin).
